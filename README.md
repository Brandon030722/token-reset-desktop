# Token重置

**把反复刷新，变成有消息时的一次提醒。**

一个常驻 Mac 菜单栏的小工具：关注 Tibo 的公开动态，查看 Codex 每周额度，把值得关注的重置消息和下一次恢复时间记下来。

**当前版本：0.1.1**

[下载 Mac 版](https://github.com/Brandon030722/token-reset-desktop/releases/tag/v0.1.1) · [在线观察看板](https://brandon030722.github.io/token-reset/) · [更新记录](CHANGELOG.md)

## 可以做什么

### 平时收起来，需要时点开

黑底白字的 **T!** 图标常驻屏幕顶部。点击打开独立面板，关闭面板后仍继续监控，不需要一直开着网页。

面板分为四页，每页只呈现一类信息：

| 页面 | 你能看到什么 |
| --- | --- |
| 概览 | 当前重置信号、最近检查结果 |
| 动态 | 相关推文、公告内容和原帖入口 |
| 我的额度 | 本机 Codex 的每周剩余额度、下一次恢复时间、个人周邮件状态 |
| 提醒 | 邀请订阅、邮箱确认、订阅管理和系统通知设置 |

### 关注公开的重置消息

约每 **15 分钟**检查一次 Tibo 的公开动态，整理与 Codex 额度重置有关的线索。

- 广泛重置信号评分达到 **80 分**时提醒，同一事件避免重复打扰。
- 明确的小范围重置或补偿公告也会触发本机通知，并注明适用范围。
- 支持回看相关动态和原帖，判断提醒的依据。

### 记住你的每周恢复时间

读取本机 Codex 的实际每周额度和下一次恢复时间。开启个人周邮件后，软件会把这个时间预约到云端。

**已经同步成功的预约，电脑关机或休眠时也能发邮件。** 不需要等你重新开机。

你可以在「我的额度」查看下一次提醒和同步状态，也可以关闭周邮件。下一周期需要软件再次读取新的恢复时间，不会自行假定每七天循环。

### 有邀请码，就把提醒送进邮箱

**看板和本机功能免费使用，无需邀请码。邮件提醒采用邀请制。**

1. 在「提醒」填写你的邮箱和邀请码。
2. 打开确认邮件，完成邮箱确认。
3. 回到应用检查确认状态，即可接收公共重置信号邮件。
4. 如需个人每周到点邮件，在「我的额度」单独开启。

邮件由 **Token重置统一发送**，你不需要准备发件邮箱或配置邮件服务。可以随时退订；个人周邮件只发给你自己的邮箱。

邀请码请向邀请人获取，仓库和安装包不附带有效邀请码。

## 开始使用

目前提供 **Apple 芯片 Mac（M1 及更新机型）**版本，Windows 暂未提供已验证的安装包。

下载并解压后，将 **Token重置.app** 放入「应用程序」并打开。之后点击屏幕顶部的 **T!** 查看面板，也可以用 Spotlight 搜索「Token重置」。需要本机通知时，请允许系统通知权限。

更新前先退出旧版本，再替换应用。邮件功能升级为邀请制，旧版本地邀请码不再有效，需要完成新版邮箱确认。

## 关于提醒

**80 分是信号强度评分，不代表重置有 80% 的发生概率。** 公开动态可能遗漏或延迟；每周邮件表示记录的恢复时间已到，不代表已经确认额度到账。检查和投递可能延迟，请以 Codex 实际显示为准。

关闭面板仍会监控，退出应用或关机则暂停本机检查；已同步的云端邮件预约继续有效。关闭预约或退订需要联网完成，已发出的邮件无法撤回。

Codex 登录信息和额度用量留在本机。开启个人周邮件后，仅将提醒所需的邮箱关联、额度名称和恢复时间等信息用于云端预约。

这是独立的公益项目，不属于 OpenAI 或 X 官方服务。
