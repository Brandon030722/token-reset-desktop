# Token重置 · Windows

解压整个压缩包，双击 **TiboMonitor.exe** 即可使用。请保留同目录里的其他文件。

- 四个页面：概览、动态、我的额度、提醒。
- 黑底白字的 **T!** 图标常驻任务栏右侧；关闭面板后仍继续监控，右键图标可退出。
- 约每 **15 分钟**检查公开动态和本机 Codex 每周额度。
- 邮件采用邀请码和邮箱确认，由 Token重置统一发送。
- 开启个人周邮件后，已同步的预约在关机时也能发信。

Windows x64 版本适用于 Intel / AMD 64 位电脑。压缩包已包含应用运行所需的 .NET，不需要安装 Python 或 Node.js。

界面使用系统的 Microsoft WebView2。若电脑缺少该组件，应用会提供微软下载入口。第一次启动可能需要稍等片刻。

## 我的额度没有数据

先确认 Windows 本机 Codex 已安装并登录。只安装在 WSL 中的 Codex 暂不支持直接读取。如果程序没有自动找到 Codex，可以右键 T! →「高级选项」→「选择 Codex 程序…」，选择本机 codex.exe。

读取成功后才会显示每周额度和恢复时间，不会自行编造时间或使用五小时窗口代替每周额度。

## 通知和邮件

Windows 托盘通知是否弹出取决于系统通知设置和勿扰模式。可在高级选项里发送一条测试通知。测试通知不发送邮件。

没有邀请码，也可以使用看板、公开动态和本机额度功能。有邀请码时，在「提醒」填写邮箱和邀请码，点击邮件中的确认按钮，再回到应用检查状态。

云端预约只提醒已记录的恢复时间；下个周期需要本机再次读取。80 分是信号强度，不是 80% 的发生概率。检查、公开来源和投递都可能延迟。
