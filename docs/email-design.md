# 邮件视觉与投递验证

邮件沿用 Ark UI 的 POPUCOM / moderate（泡姆第二档）方向：深色品牌栏、圆润 T! 标识、蓝色信息卡和暖黄色操作按钮。参考的是 [POPUCOM 官方网站](https://popucom.hypergryph.com/)的色彩和动作层级，代码为原创，不包含官方图像、字体或生产资源。

`monitor/email_design.py` 维护两种邮件：订阅确认与阈值提醒。确认邮件只解释提醒频率和确认动作；阈值邮件把评分、适用范围、北京时间、最多三条证据与原帖放在同一张卡片中。文案中的实验性评分说明、真实来源和退订入口始终保留。

布局使用 presentation table、内联样式、安全字体和流式宽度，没有远程图片、脚本或动画。小屏幕补充 padding 调整；邮件客户端忽略圆角或媒体查询时，正文和链接仍可使用。品牌 T! 用文字绘制，桌面应用图标没有修改。

网页技能的通用审计中，CSS 变量、网页 landmarks 和 reduced-motion 提示不直接适用于此邮件模板：内联色值与表格用于邮件兼容，没有需要关闭的动画。仍保留清晰链接、可见键盘焦点与小屏布局。已检查桌面与 360px 排版，最终送达效果还通过真实 QQ 邮箱验证。

测试邮件的示例评分必须带“样式预览 · 测试邮件”提示，不能写入真实监控数据库或作为真实重置公告。确认邮件使用 Brevo 的 `{{ doubleoptin }}`；提醒邮件使用 `{{ unsubscribe }}`。这些占位符只在 Brevo 真实投递时替换，静态 HTML 预览不能用于真实订阅或退订。
